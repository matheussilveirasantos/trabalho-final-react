## 🛠️ Tecnologias Utilizadas

- **React** (Componentes funcionais e Hooks)
- **React Router Dom** (Navegação entre telas)
- **Axios** (Consumo de API HTTP)

---

## 📋 Requisitos Implementados

Critérios do trabalho que foram criados no projeto:

* **Hooks do React**: Uso de `useState`, `useEffect` e `useContext` (para o Modo Escuro e Login).
* **Props**: Passagem de dados entre componentes para reutilização de código.
* **Componentes e Telas**: O projeto possui `[X]` componentes e 5 telas principais.
* **Rotas**: 4 rotas configuradas para navegar pelo site sem recarregar a página.
* **Tela de Login**: Sistema de acesso simulado ou integrado com a API.
* **Consumo de API (Axios)**: Conexão direta para buscar e enviar dados usando as rotas HTTP:
  * 🟢 **GET**: Para listar os dados na tela.
  * 🔵 **POST**: Para cadastrar novas informações.
  * 🟡 **PUT**: Para atualizar dados antigos.
  * 🔴 **DELETE**: Para apagar registros.
* **Filtro de Busca**: Opção de filtrar a lista de `[produtos]` por texto.
* **Validação de Formulários**: Inputs com avisos de erro para campos vazios ou incorretos.
* **Acessibilidade (Modo Escuro)**: Botão para alternar o visual do site entre tema claro e escuro.
* **Git**: Projeto versionado usando o GitHub.

---

## 💻 Telas do Projeto

O site conta com as seguintes páginas:

1. **Tela de Login**: Validação de usuário e senha.
2. **Dashboard / Home**: Tela inicial com o filtro de busca de `[itens]`.
3. **Cadastro**: Formulário (POST) com inputs validados para criar novos dados.
4. **Detalhes / Edição**: Espaço para ver mais informações (GET) e atualizar os dados (PUT).
5. **Configurações / Perfil**: Onde fica a opção de deletar a conta (DELETE) e ativar o Modo Escuro.

## 🚀 Como Rodar o Projeto

Siga os passos abaixo para testar o projeto no seu computador:

1. Faça o clone deste repositório:
```bash
git clone https://github.com[seu-usuario]/[seu-repositorio].git
```

2. Entre na pasta do projeto:
```bash
cd [nome-da-pasta]
```

3. Instale as dependências necessárias:
```bash
npm install
```

4. Inicie o servidor de testes:
```bash
npm start
```

5. Abra o navegador no endereço: [http://localhost:3000](http://localhost:3000)
